# Formel1-LOGGER

Web-App zum Aufschreiben von Formel-1-Spieltagen (Rennen) im Freundeskreis: Startplätze und Endplatzierungen, Punkte je Saison, nicht angetreten / ausgefallen, Statistik mit Kuchendiagrammen sowie Termine für den Kalender.

- Bis zu 8 Spieler, Namen und Punkte für Platz 1–6 legst du für jede Saison neu fest.
- Kurse stehen in einem Auswahlmenü (nur Kurse, die in der Saison noch nicht gefahren wurden).
- Statistik: Anzahl je Platz, Gesamtpunkte, nicht angetreten, ausgefallen, Startplatz → Endplatz, Diagramme.
- Läuft im Browser und lässt sich zum Home-Bildschirm hinzufügen (iPhone, Android, PC).

**Aufruf:** https://snoopy-wup.github.io/formel1-logger/

Die Spiel- und Saisondaten liegen **nicht** in diesem Repository, sondern nur lokal im Browser bzw. in der App des jeweiligen Geräts. Sicherung und Übertragung über „Export / Senden“ und „Import“.
